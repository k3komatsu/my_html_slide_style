# 表示モードとスライドの非表示条件

初期状態では全スライドを表示します。「授業」「配布」「自習」などの表示モードを定義し、各スライドに、そのモードで非表示にする条件を設定できます。スライド本文は削除されず、全表示に戻すと再び表示できます。

## ブラウザで設定する

1. Mキー、または右上のアイコンで表示メニューを開きます。
2. 「表示モード」横の「設定」を押します。
3. モード名を入力して追加します。既存のモード名は変更でき、不要なモードは確認後に削除できます。テンプレートには「授業」「配布」「自習」を用意してあります。
4. スライド一覧で「非表示：授業」などのチェックを付けます。複数のモードを指定できます。
5. 「表示モード」で使用するモードを選びます。「全表示」ではすべての非表示条件を無視します。

設定画面には非表示のスライドも残るため、チェックを外して再表示できます。ページ送り・通常の一覧・ミニマップ・印刷では、選択したモードの非表示スライドを飛ばします。右下のページ番号は表示中の本文スライドだけで振り直します。URLの番号付きハッシュは元のスライド順のままです。非表示スライドへのリンクを開くと、後ろにある表示スライドへ移動し、後ろにない場合は最後の表示スライドへ移動します。

1枚表示の画面では、Mメニューの「このスライドの非表示条件」から、表示中のスライドに同じチェックを付けられます。一覧設定と同期し、変更は自動保存します。全表示で作業するとチェック後もそのスライドが表示され、メニューを開いたまま複数の条件を設定できます。選択中のモードで現在のスライドを非表示にした場合は、別の表示スライドへ移動します。表紙・章扉もMキーから設定できます。モードを固定して書き出した単一HTMLには、このチェック欄を表示しません。

すべてのスライドを非表示にしたモードへの切り替えはエラーになります。選択中のモードで最後の表示スライドを非表示にする操作も受け付けません。

## 保存して配布や出力に使う

変更は同じブラウザ・同じ配信元・同じHTMLのパスの`localStorage`へ自動保存します。ブラウザで選択したモードも復元します。ブラウザの設定によっては保存できないことがあります。保存に失敗しても変更は画面内で保持し、設定画面に警告を表示します。不正な保存データは上書きしません。

「設定を書き出す」で`slide.visibility.json`をダウンロードします。「設定を読み込む」で別のブラウザへ引き継げます。不正なファイルや、この資料に存在しないスライドの条件を含むファイルは受け付けません。

ブラウザの操作だけではプロジェクトや公開サーバーのファイルは更新されません。配布時の設定として使うには、書き出したファイルをプロジェクト直下の`slide.visibility.json`へ保存し、ビルドします。別の名前を使う場合は`slide.config.mjs`の`visibility`にプロジェクトからの相対パスを指定します。既定の設定ファイルがない場合は、モードなしの全表示になります。設定ファイルはGitで管理できます。

```sh
node tools/slide.mjs build
```

ブラウザに既に保存した設定は、埋め込んだ配布設定より優先されます。配布設定に合わせたいブラウザでは、その設定ファイルを読み込んでください。モードを固定して書き出した単一HTMLではブラウザの保存設定を使いません。

## PDFと単一HTMLの出力

`--mode`にはモードの名前またはIDを指定します。`all`は全表示です。PDFは指定モードの表示スライドだけを出力します。単一HTMLでは非表示スライドの本文を除去し、指定モードに固定します。受け取った人がモードを切り替えて非表示資料を表示することはできません。

```sh
node tools/slide.mjs export pdf dist/授業.pdf --mode 授業
node tools/slide.mjs export single dist/自習.html --mode 自習
node tools/slide.mjs export pdf dist/全表示.pdf --mode all
```

ブラウザから書き出した設定をプロジェクトへ置かず、出力時だけ指定することもできます。

```sh
node tools/slide.mjs export pdf dist/配布.pdf --mode 配布 --settings ~/Downloads/slide.visibility.json
node tools/slide.mjs export single dist/自習.html --mode 自習 --settings ~/Downloads/slide.visibility.json
```

`--all-modes`は全表示と、定義した各モードをまとめて出力します。出力先の末尾にモード名を付けます。ファイル名に使えない文字はアンダースコアへ置き換え、同じ出力名になる場合はエラーになります。PDFは既存ファイルを上書きしません。一括出力では、表示スライドの有無と既存PDFの有無を全モード分確認してから出力を始めます。

```sh
node tools/slide.mjs export pdf dist/slides.pdf --all-modes
node tools/slide.mjs export single dist/slides.html --all-modes
```

テンプレートのモード名の場合、`slides-all.pdf`、`slides-授業.pdf`、`slides-配布.pdf`、`slides-自習.pdf`を作成します。`--all-modes`と`--mode`は同時には使えません。

`--mode`を省略したPDFは、設定ファイルの初期表示モードで出力します。`--mode`を省略した単一HTMLには全スライドと設定を含め、閲覧時にモードを切り替えられます。`export site`にはモード固定の指定はなく、全スライドと設定を含むサイトを出力します。

## スライドを編集するとき

非表示条件はスライドの識別子に結び付きます。本文を後から編集するスライドには、`parts/`のソースで一意な`id`を付け、編集・並べ替え後も同じ`id`を保持してください。テンプレートのサンプルにはあらかじめ付けてあります。

```html
<section class="slide" id="sampling-theorem">
  <h1 class="slide__title">標本化定理</h1>
</section>
```

既存の`data-slide-id`がある場合は、それを優先します。どちらもないスライドには、本文から算出した識別子をビルド時に付けます。本文を変えずに並べ替えれば同じ識別子になりますが、本文を編集すると識別子が変わります。

対象が見つからなくなった非表示条件はブラウザ内で保持し、設定画面に警告を表示します。削除したスライドの条件が不要であることを確認してから「見つからない非表示条件を削除」を押してください。CLI出力は対象不明の条件を含む設定では失敗します。誤ったスライドへ条件を付け直すことを防ぐため、設定を見直してから再出力してください。

設定ファイルは次の形式です。`defaultMode`の空文字は全表示を表します。`all`と`全表示`は予約語です。モードのID・名前は重複できません。

```json
{
  "version": 1,
  "modes": [{ "id": "lecture", "name": "授業" }],
  "hidden": { "sampling-theorem": ["lecture"] },
  "defaultMode": ""
}
```
